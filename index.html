VAG Essentials Help

Welcome to your personalized dashboard! This page gives quick access to your key resources, organized into groups.

  • Opening links
    Click any tile to open the resource in a new tab. The "My Notes" tile links to Google Keep.
  • Customizing the dashboard (Edit Mode)
    Click Enter Edit Mode. You will be asked for a PIN the first time.
    Once unlocked you can:
    • Click the red × on any tile to delete it
    • Click "Edit" on a tile to change its title, URL or image
    • Use a + in the title for a line break (Title+Subtitle)
    • Drag tiles to reorder them or move them between groups
    • Click "Edit Label" next to a group name to rename it
    • Click "Add Tile" to create a new resource
    • Click the ✏️ Edit Title button to change the dashboard name
    • Click Create Blank Slate to wipe everything and start fresh
    Editing stays unlocked until you close or reload the page.
  • Sharing
    The best way to share is to send the HTML file itself. The person who receives it can open it and customize it further.
  • Export / Import
    Use these buttons if you want to manually copy the configuration as text.
  • Reset
    Restores the original default tiles and groups.
